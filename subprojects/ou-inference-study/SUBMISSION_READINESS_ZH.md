# 投稿前研究审查：不能用完成度代替原创性

研究审查日期：2026-10-15；归档验证更新：2026-10-21。此表记录本项目的证据与缺口，不给论文或期刊贴
“一区达标”标签，也没有核定具体目标期刊的当年中科院分区。

## 当前应聚焦的科学问题

**短观察窗口、未知观测噪声和固定观测预算下，漂移信息到底有多少；
如何让置信集合既有覆盖控制，又诚实地反映不可识别与精度损失？**

这是比“五种随机过程的模拟展示”更聚焦的研究问题。基础实验作为教学
与复现背景保留，论文主线应集中在 OU 推断的假设、信息与校准。

## 逐项审查

| 维度 | 本仓库提供的证据 | 尚未满足的关键条件 |
| --- | --- | --- |
| 研究问题 | 固定窗口、噪声失配、边界与覆盖问题明确 | 还需说明相对于最接近已发表工作的不可替代贡献 |
| 文献定位 | 已核对 OU 偏差、噪声似然、Monte Carlo 检验等原始文献 | 不是系统性原创性检索，不能排除已有相同构造 |
| 理论 | 无噪声平稳模型下的连续参数格覆盖证明；噪声模型的似然、信息与弱信号限制推导 | 未证明未知噪声下兼具覆盖与有用精度的新方法 |
| 对照方法 | 条件回归、剖面、bootstrap、平稳排名、噪声 ML 与 REML | 还需针对最终主张确定最强的已发表竞争方法并严格复现 |
| 数值设计 | 固定设计、失败分母、MC SE、独立确认、假设失效对照 | 当前仍是选定参数设计；不等于统一覆盖或一致优越性 |
| 数值可靠性 | 独立矩阵、滤波、残差对照；优化器审计与边界记录 | 多起点/差分进化不构成全局最优或浮点误差的通用认证 |
| 研究透明度 | 逐次记录、种子、源码/配置/档案校验值、独立逐条归档校验及损坏测试 | 内部方案不等于外部预注册；哈希不认证真实来源；尚无正式存档 DOI |
| 论文论证 | 工作稿与分阶段补充稿，区分证明和经验观察 | 还需合并成一个主张清晰、结果互相支撑的投稿稿件 |
| 真实应用 | 目前全部数据是合成数据，真值已知 | 若最终主张面向应用，需可追溯真实数据与独立验证；纯方法论文是否需要由论证决定 |
| 外部审查 | 软件自动检查可重复 | 尚无领域专家独立审读、同行评审或录用结论 |

## 本轮工作如何推进

[含测量误差的研究](measurement-error/README.md)补足上一阶段使用错误
观测模型的薄弱点。它实现完整联合高斯似然和 REML，并把初始分布处理、
噪声建模、重复测量与优化失败分别记账。信息论推导解释某些场景为什么
难以区分漂移参数，避免把任何失败都归因于代码或样本量不足。

这些方法和工具都有已有理论基础。即使新结果更好，也不能仅凭较高的
覆盖率或较低的条件 RMSE 宣布“新方法优越”或“一区水平”。

## 下一项能够改变论文贡献判断的工作

2026-10-21 的[独立归档校验](../../notes/ARCHIVE_VALIDATION.md)核对噪声阶段
全部 9,000 条记录与汇总，并增加在篡改或损坏副本上的拒绝测试。
它提高了公开结果的一致性与可检查性，没有新增科学实验或原创性结论。
[中文证据指南](../../notes/RESEARCH_EVIDENCE_ZH.md)帮助区分证明、数值观察
与软件检查。此前科学提交的三版本完整 CI 已成功，链接见归档校验说明。

1. 明确一个可反驳的原创主张，例如在指定噪声与窗口范围内，同时给出
   覆盖误差上界、非平凡集合直径界和可计算算法。
2. 对这个精确主张开展定向文献核查；如已有结果，改变科学问题而非改名。
3. 给出完整假设、证明与边界反例，尤其解释信号趋零时为什么必须放宽
   精度要求。不能提出与信息限制矛盾的统一窄区间承诺。
4. 冻结算法和设计，用独立随机数及最接近已发表方法作确认，报告覆盖、
   精度、功效、计算成本与失败率。
5. 由研究者独立解释每个公式，安排领域审读，再按具体目标期刊的范围、
   当年分区和投稿规范整理稿件。

本轮完成的是可核查的研究推进。论文原创性和期刊判断必须由实际成果、
文献与同行评审共同支持，不能由仓库自动测试代替。
