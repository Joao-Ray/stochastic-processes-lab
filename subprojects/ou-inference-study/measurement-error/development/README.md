# Historical numerical diagnostics

These files preserve the two diagnostics described in [AMENDMENTS.md](../AMENDMENTS.md).
They are software-development evidence, excluded from final scientific tables
and from the 9,000 final-attempt count. Embedded source hashes refer to the
pre-repair implementations, so they are historical identifiers rather than
checksums of the current source. The saved raw observations, evaluated
objectives and profile grids support the regression tests and make the
numerical discrepancies independently inspectable. They do not claim to
archive every discarded run or certify an externally registered protocol.
